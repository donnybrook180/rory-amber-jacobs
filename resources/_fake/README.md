# Quarantined placeholder masters — DO NOT use as a build source

These 16 spreadsheets look like 5000-word masters but are not. Each holds only
~220–260 distinct words, recycled ~20× with the rank appended in parentheses
(`kommen (67)`, `مشى (160)`). One full `build_all.py` run against any of them
would overwrite a real published word list with ~250 recycled rows.

They were moved here from `resources/` so no build can consume them. See
`docs/word-quality-plan.md` (app repo) §Phase 0.

The **real** English master (`resources/Top_5000_Engelse_Woorden_Meertalig_Master.xlsx`,
5000 distinct) stays in `resources/`. Note it carries only 17 native-language
columns; the live English list ships 21 (`tr`, `pl`, `el`, `bn` were added
out-of-band), so even that master is stale for a straight rebuild.

For every language except English, the committed `<lang>/words.*.json` is the
source of truth — generated by `tools/gen_lang_content.py`, not from these files.
